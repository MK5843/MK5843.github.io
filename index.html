SiteGiant → Xero: Multi-Channel Invoice Automation Flow with APIs

Title/Role:
IT/E-Commerce Lead & Shopify Expert · Team Collaboration

The Problem:
◦ Invoice syncing between SiteGiant and Xero was done manually. Staff had to run the sync, check the results and handle errors across multiple sales channels, which took time and could lead to missed or incorrect invoices.

Overview:
◦ Built an automated flow invoice sync between SiteGiant and Xero using their APIs and Microsoft Power Automate, replacing the manual syncing process.

What I did:
◦ Investigated the existing manual invoice sync process and identified areas that could be automated.
◦ Built six Power Automate flows to handle invoice syncing across different sales channels.
◦ Integrated the SiteGiant Open API to retrieve order data and the Xero API to create invoices.
◦ Added automatic Xero token refresh so the integration could continue running without manual re-authentication.
◦ Added rules to handle different sales channels, including RedMart, Decathlon and POS orders such as auto-fill sales account number and channel.
◦ Added B2B order checks to exclude these orders from the automatic sync for separate handling.
◦ Added error handling and fallback values to prevent incomplete order data from stopping the process.
◦ Added sync history notes in SiteGiant and Xero to make invoice processing easier for accounting team to track whether the order was "Paid" or "Cancelled".

Outcome:
◦ Automated the processing of 1,000+ invoices per month, eliminated the manual sync process and reduced invoice errors by 90%.
